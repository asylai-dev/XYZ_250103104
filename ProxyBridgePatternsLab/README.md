# Proxy & Bridge Patterns — Java Lab

All six tasks from the provided worksheet are implemented in plain Java.

## Run in IntelliJ IDEA
1. Extract the ZIP.
2. Open the `ProxyBridgePatternsLab` folder in IntelliJ IDEA (Open).
3. Open `src/Main.java` and click the green Run triangle next to `main`.
4. Check the console: each task is labeled Task 1 through Task 6.

## Run from terminal
```bash
cd ProxyBridgePatternsLab
javac -d out src/*.java
java -cp out Main
```

No external libraries, database, or Maven setup required.

## Structure
- Tasks 1–3: Proxy (access control, view tracking, school firewall).
- Tasks 4–5: Bridge (devices and remotes).
- Task 6: Bridge (heroes and weapons).
